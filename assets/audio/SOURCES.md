# CASHYPHUS audio sources and transformations

All source recordings below are CC0 according to their individual OpenGameArt pages. Originals are retained unmodified in `assets/audio/sources/`, which is kept on disk for re-baking and deliberately not committed: the game loads only the rendered files, and every input can be fetched again from the URL in its row. The exported WAV and OGG files are edits and arrangements made for this game by `tools/build_audio.py`, a deterministic offline DSP script. No generative audio model was used and no sound here is synthesised from a prompt: every delivered file is a transformation of one or more of the recordings listed below. The script itself was written with the help of an AI assistant, and what it does to each input is stated in the table. CC0 permits commercial use. Attribution is given voluntarily.

The 20 WAV effects are 44.1 kHz, 16 bit mono, and the walk-away ambience is a 44.1 kHz stereo OGG Vorbis loop of 19.2 seconds. Source effects are deliberately short and layered to resemble register impacts where appropriate.

The game's music is not made from these recordings. It is MintoDog's CC0 chiptune, baked into the binary as a sample table and worn down as incarnations pile up -- credited, with the arrangement it gets, in [`../CREDITS.md`](../CREDITS.md).

`Cash Register (imitation with toaster and bells)` on Freesound was not downloaded because its authenticated download was not available here. `reincarnation.wav` is the documented substitute, built from a selected money movement, Spring Spring’s purchase recording, and a bright coin strike from the verified CC0 sources above. The selected Kenney and OwlishMedia files are retained; unused files from those large packs are omitted. The source task’s Freesound recording remains unavailable without authentication.

To regenerate, build the native game once for `cashyphus_decode`, install NumPy and ensure system `libsndfile.so.1` is available, then run `python3 tools/build_audio.py`. The generator reads the retained original files and never modifies them. `python3 tools/verify_audio.py` then measures every delivered file -- format, length, level, DC and the loop seam -- checks that the baked climb theme is present and is not a placeholder, and fails if any of it drifts.
